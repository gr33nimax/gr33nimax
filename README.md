# gr33nimax

Развиваю экосистему **HYDRA** — сервер, сетевое ядро и Android-клиент для self-hosted VPN.

- [HYDRA-ULTIMATE](https://github.com/gr33nimax/HYDRA-ULTIMATE) — установка и управление прокси-протоколами и маршрутизацией.
- [hydracore](https://github.com/gr33nimax/hydracore) — сетевое ядро для Android.
- [hydrabox](https://github.com/gr33nimax/hydrabox) — Android-клиент с подключением по подписке.

Оформление Material 3 и статистика обновляются автоматически через GitHub Actions.
